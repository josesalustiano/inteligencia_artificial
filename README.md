## Descrição
Este repositório contém a análise exploratória e o pré-processamento de dados para a primeira atividade da disciplina Inteligência Artificial. O objetivo é preparar o dataset "Social Media Addiction and Mental Wellbeing" para dois problemas: regressão e classificação.

## Estrutura
- `data/raw/`: Dataset original
- `data/processed/`: Datasets após limpeza
- `notebooks/`: Notebooks com as análises
- `reports/figures/`: Gráficos gerados
- `src/`: Funções auxiliares

## Como Executar
1. Clone o repositório
2. Instale as dependências: `pip install -r requirements.txt`
3. Execute os notebooks na pasta `notebooks/` em ordem numérica.
